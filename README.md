# SPIRA — Pure • Natural • Superfood Spirulina

Official E-Commerce Storefront, Progressive Web App (PWA), Visitor Analytics & Marketing Control Center for **SPIRA Bangladesh**.

## Features
- **Organic Superfood Storefront**: Spirulina Powder, Veg Capsules, and On-The-Go Mini Sachets.
- **Protected Admin & Marketing Control Center**: Password-protected (`spira123`) dashboard for 1-click `COMING SOON` / `STOCK OUT` red ink stamp overlays, product photo uploads, live visitor funnel analytics, Facebook (Meta) Pixel tracking, and order notifications.
- **Progressive Web App (PWA)**: Installable on Android, iOS, and Desktop directly from the browser.
- **Supabase Cloud Ready & Vercel Configured**: Includes `supabase_schema.sql` and `vercel.json` for instant deployment.
